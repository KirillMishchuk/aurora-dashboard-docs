# DOCS — карта репозитория

Этот репозиторий — рабочая база знаний и документация по проекту SAP (Aurora Dashboard + смежное). Ниже — что лежит в каждой папке, зачем она нужна и как соотносится с остальными.

| Папка | Что это | Статус содержимого |
| --- | --- | --- |
| [`aurora-dashboard-kb/`](./aurora-dashboard-kb/) | Основная база знаний по репозиторию `aurora-dashboard`: обзор, архитектура, пакеты, workflow разработки, domain-map, плюс `prs/` — пост-мерж отчёты по PR. Обновляется скиллом `update-kb`, привязана к конкретному коммиту (см. пин в `README.md`). | Верифицированная, пин на конкретный коммит |
| [`plans/`](./plans/) | Рабочий журнал планирования: планы имплементации фич и фиксов перед/во время написания кода, с таблицей статусов (не начато / в работе / реализовано). | Живой, часто меняется |
| [`pr-reviews/`](./pr-reviews/) | Черновые ревью-находки по PR до мержа (вывод скилла `code-review`) — то, с чего потом рождаются планы в `plans/` и на что позже ссылается пост-мержевый отчёт в `aurora-dashboard-kb/prs/`. | Черновой, привязан к состоянию PR на момент ревью |
| [`ToolDocs/`](./ToolDocs/) | Обсидиан-хранилище со справочной информацией по используемым тулам: `ClaudeDocs/` (заметки по Claude Code), `claude-config/` (копии конфигов Claude Code для aurora-dashboard). | Справочный, редко меняется |
| [`ai-dev-tasks/`](./ai-dev-tasks/) | Внешний шаблон-репозиторий (сторонние markdown-инструкции для PRD/тасков), подключён как read-only референс. | Внешний, не редактируется |

## Как это соотносится

- **`pr-reviews/` → `plans/` → `aurora-dashboard-kb/prs/`** — это последовательность жизни одного PR в этой базе: сначала черновые находки ревью (`pr-reviews/`), затем при необходимости план фикса (`plans/`), и уже после мержа — итоговый отчёт о том, что реально попало в `main` (`aurora-dashboard-kb/prs/`). Три папки не дублируют друг друга — они фиксируют разные моменты времени.
- **`aurora-dashboard-kb/`** — единственное место, которое претендует на «текущую истину» о репозитории; у него есть явный пин на коммит и процедура обновления. `plans/` и `pr-reviews/` сознательно не влиты в неё — они привязаны к скиллам с зашитыми путями (`plans/<date>-...md`, `pr-reviews/pr-<n>-review.md`) и живут по своей логике версионирования.
- **`ToolDocs/`** и **`ai-dev-tasks/`** — не про сам aurora-dashboard, а про инструменты вокруг него; читать их нужно реже и по другому поводу.
