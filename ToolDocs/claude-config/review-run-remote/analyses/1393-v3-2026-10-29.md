## 5. Script/protocol problems

### 5.1. `check_run.py` — ложный "no agents launched"

- **Проблема:** `checks.md:47` "Agents launched vs listed by briefs.py: [!] no agents launched"
- **Почему:** `check_run.py` ищет в orchestrator log (`session.jsonl`) строки Agent tool use (spawn), но в этом логе смешаны прогон скилла (10:23–~11:35) И диагностика (10:48–10:52). Диагностическая часть не имеет Agent calls — скрипт увидел её как конец и решил, что агентов не было.
- **Насколько плохо:** Не влияет на результат — run folder полный, все 14 агентов отработали (briefs + out/ совпадают). Это ложная тревога из-за смешанного лога.
- **Как исправить:** `check_run.py` должен игнорировать сегменты лога после завершения скилла (Step 9 FOLLOW-UPS или последний AskUserQuestion) — либо флаг `--session-part <start_time>-<end_time>` для ручной границы.

### 5.2. `run_review.py --save` не скопировал `session/subagents/`

- **Проблема:** `1393-v3/session/` пуст — `run_review.py --save 1393-v3 --last 1` скопировал `session.jsonl`, но не `9ad5df1c.../subagents/`.
- **Почему:** `run_review.py` строка 86–88: `folder = log.with_suffix("")` (убирает `.jsonl`, ожидает `9ad5df1c.../`), `if folder.is_dir(): shutil.copytree(folder, dest / tag)`. Но в `~/.claude/projects/-Users-…/` папка называется `9ad5df1c-c068-4f56-9c13-ff86a008dc94/`, а `log.stem` = `9ad5df1c-c068-4f56-9c13-ff86a008dc94`, т.е. `folder` должна совпасть. Возможно, `with_suffix("")` не сработал (UUID уже без суффикса) или папка появилась позже (субагенты пишутся постепенно, а `--save` смотрел до завершения).
- **Насколько плохо:** Критично для audit по агентам — без логов субагентов шаг 3 невозможен. Исправлено вручную `cp -r ~/.../9ad5df1c.../subagents 1393-v3/session/`.
- **Как исправить:** Проверить `run_review.py` строка 87: если `log.with_suffix("")` возвращает путь без `.jsonl`, но папка называется так же (UUID), `is_dir()` должен находить. Либо race condition — `--save` запущен до того, как все субагенты дописали логи. Добавить задержку или явный wait на `.meta.json` всех агентов.

### 5.3. Смешанный лог `session.jsonl`

- **Проблема:** Одна сессия (`9ad5df1c`) содержит `/model` (10:23), `/review-and-comment-pr 1393` (10:24–~11:35), затем диагностику (10:48–10:52) с 7 Bash calls, 6 Read, 2 ошибки.
- **Почему:** Пользователь запустил `run_review.py 1393`, скилл отработал, затем в той же сессии началась диагностика (проверка run folder, сбор логов).
- **Насколько плохо:** `audit_session.py` включает всё (28 tool calls вместо ~21 от скилла), стоимость завышена (~$1.25 vs ожидаемые $2.7–4 непонятно — либо Update дешевле, либо recount неточен). `checks.md` показывает `[!]` для всех диагностических команд (строки 15–44).
- **Как исправить:** `run_review.py` должен собирать лог сразу после выхода из Claude Code, до любой другой работы. Либо использовать чистую сессию (закрыть текущую, запустить `run_review.py` заново). Либо `audit_session.py --before <timestamp>` для отсечения tail.

**Файл:** `DOCS/ToolDocs/claude-config/review-run-remote/run_review.py`
