# pr-descriptions

PR descriptions for `aurora-dashboard`, written by the `temp-sync` skill for the change set currently staged. The user opens PRs themselves, so each file is the text pasted into the GitHub PR body by hand — nothing is posted automatically.

**Copying to GitHub:** each file starts with a properties (frontmatter) block — it is for Obsidian and must not end up on GitHub. Copy only the text below it: in Obsidian's reading view the properties block is not included in a text selection; in a plain editor, skip everything up to and including the second `---` line.

- **Naming:** `pr-<number>-description.md` once the PR exists, otherwise `pr-<kebab-slug>-description.md`.
- **Format:** follows `aurora-dashboard/.github/pull_request_template.md` (`# Summary`, `# Changes Made`, `# Related Issues`, `# Testing Instructions`, `# Checklist`).
- **Lifecycle:** accumulating — one file per PR, kept after the PR merges and never cleared (unlike [`../transfer/`](../transfer/)). Re-running `temp-sync` rewrites only the file for the current change set.
