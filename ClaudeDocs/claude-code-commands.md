# Встроенные команды Claude Code

Слэш-команды, которые даёт сам Claude Code (CLI) — в отличие от скиллов (`claude-code-skills.md`) и плагинов (`claude-code-plugins.md`), это не подключаемые модули, а часть ядра инструмента: управление сессией, контекстом, конфигурацией, плагинами, аккаунтом. Работают всегда, независимо от того, какие плагины включены.

> Список собран 24.07.2026 из справки CLI (`claude --help`) и строк, зашитых в бинарник Claude Code — команда для чтения, а не для ввода в диалоге; часть внутренних/энтерпрайз-команд опущена ради стабильности списка. Проверить актуальность: `/help` в диалоге.

## Сессия и контекст

| Команда | Описание |
| --- | --- |
| `/clear` | Начинает новую сессию с пустым контекстом; предыдущая сессия остаётся на диске и доступна через `/resume`. |
| `/compact` | Освобождает контекст, сжимая текущий разговор в саммари (то же самое происходит автоматически при приближении к лимиту). |
| `/resume` | Возобновляет предыдущий разговор. |
| `/context` | Визуализирует текущее использование контекста цветной сеткой (то, чем пользовались в этой сессии). |
| `/diff` | Показывает незакоммиченные изменения и дифф за каждый ход разговора. |
| `/export` | Экспортирует текущий разговор в файл или буфer обмена. |
| `/copy` | Копирует последний ответ Claude в буфер обмена (`/copy N` — N-й с конца). |
| `/branch` | Создаёт ответвление разговора от текущей точки. |
| `/fork` | Запускает фоновый агент, наследующий весь текущий разговор. |
| `/subtask` | Отправляет суб-агента с полным текущим контекстом; результат возвращается сюда же. |
| `/focus` | Переключает focus-режим: только промпт, саммари и ответ, без остального шума. |
| `/btw` | Быстрый побочный вопрос без прерывания основного разговора. |
| `/plan` | Включает режим планирования или показывает план текущей сессии. |

## Помощь, статус, диагностика

| Команда | Описание |
| --- | --- |

| `/skill-doctor` | Какие загруженные скиллы не используются и просто съедают контекст. |
| `/recap` | Генерирует однострочный recap текущей сессии прямо сейчас. |
| `/insights` | Отчёт-аналитика по вашим сессиям Claude Code. |
| `/powerup` | Интерактивные уроки по возможностям Claude Code. |

## Git, ревью, PR

Дополняют скиллы `code-review`/`review`/`security-review` (см. `claude-code-skills.md`) — там же описаны нюансы разницы между ними.

| Команда | Описание |
| --- | --- |
| `/review` | Ревью GitHub pull request по номеру/URL; для локального рабочего диффа — `/code-review`. |
| `/security-review` | Комплексный security-ревью незакоммиченных изменений текущей ветки. |
| `/ultrareview` | Устаревший алиас `/code-review ultra` — облачное multi-agent ревью текущей ветки (или PR/база) через Claude Code on the web. |
| `/ultraplan` | Claude Code on the web составляет план, который можно отредактировать и одобрить. |
| `/autofix-pr` | Мониторит и автоматически чинит проблемы текущего PR. |
| `/install-github-app` | Настройка Claude GitHub Actions для репозитория. |

## На заметку

- `/agents` помечена в самом Claude Code как **(removed)** — управление суб-агентами теперь через прямое редактирование `.claude/agents/*.md` (как в этом проекте) или CLI-команду `claude agents` для фоновых агентов, а не через слэш-команду в диалоге.
- CLI (`claude <command>`, не слэш-команда внутри диалога) отдельно даёт `claude doctor`, `claude mcp`, `claude plugin`, `claude agents` (фоновые агенты), `claude project`, `claude update`, `claude auth`, `claude setup-token` — это те же возможности, вызванные снаружи диалога, до старта сессии.
